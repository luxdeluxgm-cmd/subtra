# Subtra

Daily subtractive (CMYK) color-mixing puzzle game. Match the target swatch in five tries.

## Development

```bash
npm install
npm run dev
```

Create a `.env` file in the root directory:

```env
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
```

## Build

```bash
npm run build
```
